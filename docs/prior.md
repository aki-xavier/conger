# 为什么需要先验：问题的不适定性
## 逆问题与 Helmholtz 无意识推理
从二维投影恢复三维场景在数学上高度不适定：无穷多个三维场景可以产生完全相同的视网膜图像。传统三维重建用多目几何或深度传感器增加约束，代价是硬件复杂度与成本；而人类仅凭双眼（甚至单眼静态图像）就能稳定地感知三维世界，说明大脑在感觉输入之外注入了强约束——即视觉先验。
Helmholtz（1867）将此概括为"无意识推理"（unconscious inference）：感知不是对输入的直接读取，而是大脑利用过去经验对模糊感觉输入做出的最佳假设。透视关系、光照与阴影、纹理梯度、语义理解都被用来补全缺失的深度信息。这一思想是现代贝叶斯感知理论的直接源头。
## Marr 的计算视觉理论
Marr（1982）把视觉系统分析分为三个层次：
- **计算理论层**：要解决什么问题，为什么需要约束；
- **算法层**：用什么表征与算法施加约束；
- **实现层**：神经机制如何承载这些算法。
在计算理论层面，任何求解不适定问题的视觉系统都必须显式或隐式地施加约束，这些约束就是先验。Marr 提出的 2.5D 草图（surface 法线、深度梯度、边界的中间表征）本身就是一种结构化先验：它先于完整三维重建存在，为后续推断提供基底。本文在 Marr 原始定义的基础上扩展了 2.5D 草图的概念：原始定义为 viewer-centered 的单一深度/法线层，本文加入多层半透明/反光表示，将其从单层深度场推广为分层深度场。后文中的"类 2.5D 草图"均指此扩展版本。
## 贝叶斯形式化
Bayesian 视觉模型将先验形式化为概率分布，感知即最大后验推断：
$$\hat{S} = argmax_S P(S|I) = argmax_S P(I|S) \cdot P(S)$$
似然`P(I|S)`对应成像过程，先验`P(S)`对应自然世界的统计规律。代表性工作：Knill & Richards (1996) 的深度线索整合、Weiss et al. (2002)的运动感知（低速先验解释运动孔径问题）、Yuille & Bülthoff (1996)的光照与形状推断。精确贝叶斯推断通常不可计算，因此大脑被认为使用变分推断、粒子滤波、抽样等近似算法。
## 格式塔学派：先验的经验源头
在计算理论之前，Gestalt 学派（Wertheimer 1923；Koffka 1935）已从心理物理实验中归纳出一组知觉组织律：邻近性、相似性、闭合性、良好连续性（good continuation）、共同命运（common fate）、图形-背景分离。这些定律本质上就是先验假设的现象学描述，后来大多获得了几何概率（一般视角假设）或自然图像统计（良好连续性与边缘共圆性统计）层面的形式化解释。
# 先验假设分类体系
按作用域分为六类。每类给出机制描述、关键证据与对计算机视觉的启示。
## 半透明与分层先验
- **分层表示**：大脑构建的不是单一深度图，而是类 2.5D 草图的多层结构——稳定的底层（Base Layer）与高亮、低对比度或特定位移的反光/透明层。感知过程相当于从 $I = L_1 + L_2$ 中迭代解耦两个层，直到每层在语义上自洽（L₁ 像一棵树，L₂ 像一扇窗）。
- **X 结与 Metelli 约束**：半透明覆盖在边缘交叉处形成 X 形连接。只有当交叉点亮度变化符合物理"混合定律"（叠加后亮度介于两层之间）时，大脑才产生透明感（Metelli 1974）。
- **聚焦与模糊线索**：景深先验——清晰背景上的轻微模糊倒影（或反之）会被迅速归入不同深度层，频率差异是分离信号的重要判据。
对 CV 的启示：软分配（soft assignment）比硬分割更接近生物策略——保留像素属于多层的后验，而非过早 argmax。

## 几何与结构先验
| 先验      | 内容                     | 形式化证据                                          |
| ------- | ---------------------- | ---------------------------------------------- |
| 对称性     | 生物与人造物体多对称，大脑自动补全不可见半侧 | 镜像/旋转对称检测                                      |
| 紧凑性与平滑性 | 表面大多平滑，边缘与纹理变化稀疏       | 正则化项 $E = E_{data} + \lambda \cdot E_{smooth}$ |
| 平直与正交   | 室内/城市场景默认平面与直角         | 曼哈顿世界假设                                        |
| 线性透视    | 平行线远方汇聚                | Gibson (1950) 纹理梯度                             |
| 部件组合    | 复杂物体分解为几何原形组合          | Biederman (1987) Geon 理论                       |
| 物体边界    | 边界对应强梯度                | 边缘检测的本体论地位                                     |
| 最小刚性    | 多解时选刚性程度最高的解释          | Ullman (1979) SfM：3 视角 4 点定结构                  |
| 一般视角    | 观察者不处于巧合视角             | Freeman (1994) 最小规则；巧合对齐导致知觉不稳                 |
| 凸形状偏好   | 模糊形状解释为凸而非凹            | 空心面具错觉（Ramachandran 1988）                      |

对 CV 的启示：几何与结构先验是最容易被正则化项捕获的先验类别——平滑性、对称性、正交性均可直接编码为优化问题的约束项或惩罚项。但这也意味着它们的工程实现形式与神经实现机制差异最大：大脑通过关联场和横向连接实现轮廓整合，而工程通过变分正则化实现——两类实现共享同一个计算目标，不共享同一个计算路径。
## 光学先验
- **光源上方先验（light-from-above）**：人类最核心的偏见。默认光从上方照射，"上亮下暗"被判为凸起；图像旋转 180° 会使凹凸感知反转。空心面具错觉（Ramachandran 1988）是最强证据——凹面具因与上方光照一致而被强制感知为凸脸。
- **单一光源先验**：尽管真实场景多光源，大脑倾向假设单一主光源，大幅简化 shape-from-shading。
- **白平衡/光源颜色恒常性**：假设光源接近中性色，整体色相偏移会被自动校正（Land & McCann 1971 Retinex）。
- **反射率恒常性（Albedo constancy）**：亮度变化优先解释为形状转折的阴影而非表面换漆。Adelson 棋盘阴影错觉是该先验的极端演示。
- **色相线索**：阴影处色相对光源补色的偏移也携带深度信息。
对 CV 的启示：光照归一化必须在特征层完成而非仅在图像层。
## 物理先验
- **物体连续性**：材质、纹理属性空间连续。
- **重力感**：物体受重力约束，大脑自动寻找支撑关系；底部无支撑的物体触发"挂在哪里/正在掉落"的推断。
- **视平线与高度**：地平面上的物体越接近视平线越远。
- **大气透视**：远处物体对比度低、偏蓝、边缘模糊——此线索仅在户外远距离（百米级）场景有效，近距室内场景下贡献可忽略。
- **立体视差与运动视差**：双眼视差与头动产生的相对运动是最直接的度量深度线索。
- **遮挡逻辑**：轮廓 T 结——A 的轮廓切断 B，则 A 在前。这是最稳固的深度顺序判据，也是 Pb 边界图的语义基础。
对 CV 的启示：物理先验中最关键的是遮挡逻辑——它是唯一提供严格序数约束的先验（"A 在 B 前"在任何距离成立），不依赖度量校正。在贝叶斯融合中应以极高先验权重编码，且权重不应被其他线索的冲突下调。
## 运动与时间先验
- 运动连续性、速度一致性、加速度限制：物体运动轨迹平滑，突变需要外力解释。低速先验（slow-and-smooth prior）表明大脑偏向低速解释，以此解决运动孔径问题。
- 时间一致性：形状与位置在相邻帧不剧变。
- 不变性假设：颜色、纹理等属性跨视角保持稳定——这是"同一物体"判断的根基，也是跨帧聚类一致性的依据。
对 CV 的启示：运动与时间先验的工程实现高度成熟——Kalman 滤波、粒子滤波、光流方法已提供了完备的状态估计工具链。挑战不在算法本身，而在将物理运动（刚体变换）与表观变化（光照、遮挡、形变）解耦——不变性假设是解耦的理论基础。
## 语义与经验先验
- **物体类别模板**：识别出"椅子"后直接调用三维模板，而非从零计算长宽高。现代对应物：类别级形状先验、检索式重建。
- **熟悉大小**：指甲盖大的"小人"不会被判为侏儒，而是由"人高约1.7 m"反推其距离。单目深度网络学到的相当部分就是这种语义-尺寸-距离的联合统计。  
对 CV 的启示：语义与经验先验是唯一需要高层语义理解的先验类别——它们在纯底层特征管线中不可获得，需要物体识别层的输出注入。在实时系统中，这类先验的注入频率最低（物体类别变化远慢于帧率），可作为低频校正通道运行。

# 当前实现中的先验形式

本项目把先验分四层落地，而不是集中为一个 `Prior` 对象：

1. **场景族硬先验**：`Codebook` / `LayeredCodebook` /
   `CompositeCodebook` / `cga.Scene` / renderer 固定材质、相机 rig、
   光照模型和离散因子支持集; `n_objects=2` 支持双图元遮挡/前后层,
   `scene_family=composite` 支持 base + attached part 的稳定组合模板；
2. **经验统计先验**：162 组合全因子 × R 连续复制，MixtureSPN 的实例
   记忆、均匀权重和逐 kind tied variance；
3. **算法结构先验**：Riesz 多尺度、带符号色度、前景权重、双目视差
   公式、逐层 `(x,y,disparity)` 聚类、圆/方轮廓补全、遮挡联合优化、
   attached_on_top 接触线搜索与残差参数化；
4. **推理似然先验**：SceneReconstructor 用同一 renderer 对候选场景
   计残差，把反照率×光照联合歧义交回正向模型; kind 结构评分沿用共享
   几何，候选返回前再按各自的面积→尺寸代理重校准 s，避免结构选择被
   观测掩码偏差污染。

输出契约是 `StructuredHypothesis`: MAP
`cga.Scene` 只是展示层; 同时保留 SPN
原始后验、全 kind × 54 外观候选的渲染残差与联合后验、top 完整
场景假设。设计原则: 硬物理约束进支持集, 统计规律进概率/核带宽,
不适定逆问题的歧义进候选后验, 不做过早 argmax。

## 动态增量先验

类别增长与结构增长采用不同机制。类别增长发生在固定场景族内: 类别
注册表和 `cat_sizes` 版本化, 旧分量对新类别补零概率, 新颖性由责任度、
渲染残差和后验熵共同触发。结构增长改变参数维度和生成机制, 因此使用
结构专家混合而非原地改写旧模型:

\[
p(S,M\mid I)\propto p(I\mid S,M)p(S\mid M)p(M)
\]

`M` 是单物体/组合模板/双层/未来透明层等结构专家。`ExpertRegistry` 负责
注册与按需加载专家, `StructureGate` 用专家内重建残差、模板复杂度和
观测级几何证据形成结构证据; 所有专家都不兼容时才允许新结构出生。
复杂度项是最小描述长度
先验: 在残差相近时优先更少部件、更短关系的模板。出生请求可以进一步携带
残差驱动提案: 以当前最佳解释为底座, 在 depth≤2 的
attach/layer/mirror/repeat 文法中枚举少量组合, 并用正向渲染重新评分。
该设计把“学习新样本”与“发现新世界结构”
分开, 防止旧模型被不可比较的新参数空间污染。`ToySeriesFamily` 的
线性/振荡机制测试表明, MixtureSPN、结构门控和出生控制可脱离视觉输入
独立运行; 视觉路径只是该通用结构学习框架的一个领域适配器。
