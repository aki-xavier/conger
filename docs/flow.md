# 各层数学模型与先验设计（CGA 深集成版）

对应模块流程图 `res/module-flow-v2.json`。特征层（Riesz 特征 + VB-GMM）的数学细节与先验位置见 `docs/prior.md` 末节，本文覆盖其后各层：知觉组织、场景分割、单目深度线索、双眼视差、深度融合、时空累积、三维重建。已知缺口及其生物启发方案集中于第 8 节；模块间传递数据的格式汇总于附录 A。

**总体决策（方案 B：CGA 深集成）**：三维重建层输出共形几何代数（CGA）建模，且 CGA 多向量不作为出口适配器，而是作为层间的**稀疏通用语**——图元（点、点对、线、圆、面、球）与运动（motor）在各层之间以 blade/versor 形式传递。稠密场（像素、深度）与稀疏图元（CGA）之间设两个显式转换点：**提升**（稠密 → 图元拟合）与**渲染**（图元 → 预测场，共享功能，多处调用）。表示约定沿用独立包 `cga`（~/code/cga，path 依赖，原 src/cga 外迁）：点/点对/线为直接（join）形式，关联判据 `op(p, X) = 0`；平面/球/圆为对偶形式，关联判据 `ip(p, X) = 0`。

**概率推断统一为贝叶斯网络（Bayesian Network / DAG）**：全架构所有概率推断层统一为有向无环图框架。特征层（VBGMM）为生成式 BN；场景分割为层级 BN（替代 MRF/CRF）；双眼视差为空间自回归 BN（替代 MRF 能量最小化）；深度融合为 BN 乘积法则；时空累积为动态 BN（Motor-EKF）；三维重建为 BN 贝叶斯更新。无向图模型（MRF、CRF）仅在历史文献对照中出现，不作为架构成分。

**前提约定**：全管线假定相机内参 $K$ 已知（标定在系统外完成，见第 8 节缺口 C1）。2D 图像量与 3D 场景量是**两个空间的对象**，经 $K$ 互相转换；组织层在 2D 共形子代数（$\{e_1, e_2, e_0, e_\infty\}$）中工作，3D 场景图在完整 5D CGA 中工作，两者的映射规则在各层显式声明。

## 符号约定

- $r_{nk}$：像素 $n$ 对分量 $k$ 的后验责任（VBGMM 输出）
- $L_e, L_t$：边缘/纹理类后验似然图（`class_likelihood` 输出）
- $\theta_n$：像素 $n$ 的结构法向（`mean_ori`），$R_n$：方向一致性（`ori_R`）
- CGA 对象：$p$（点，grade 1 直接）、$Pp$（点对，grade 2 直接）、$L$（线，grade 3 直接）、$\pi$（平面，grade 1 对偶）、$s$（球，grade 1 对偶）、$C$（圆，grade 2 对偶）、$M$（motor，偶次 versor）
- $d$：深度（单目通路）或视差（双目通路）；$K$：相机内参

## 0. CGA 深集成总纲

### 0.1 两个转换点

- **提升（lifting）**：稠密场 → CGA 图元。发生两处：组织层边缘（edgel 链 → `point_pair`/`line`，2D 共形子代数内）、融合/重建层表面（深度场区域 → `plane`/`sphere` 拟合，5D CGA）。提升是**估计**——输入是带后验的稠密证据，输出是图元参数 + 不确定度。
- **渲染（rendering）**：CGA 图元 → 稠密预测场，**共享功能，两处调用**：预测编码（重建层 → 特征/分割/融合层的虚线反馈边）与运动视差预测（时空层 → 融合层的虚线边）。射线（`line`）与图元求交（`meet`），残差用 `dist_point_plane` / `dist_point_point` 计算。

### 0.2 不确定度接口（关键设计决策）

上游各层是概率对象（后验、ELBO、软分配），CGA blade 是确定性几何对象。**"概率 CGA" 没有成熟理论可援引**，因此显式约定：

- 图元用**最小参数化 + 高斯不确定度**承载：平面 $(\mathbf{n}, d)$ 4 参数、球 $(\mathbf{c}, \rho)$ 4 参数、线（Plücker 6 参数）等，各带协方差 $\Sigma$，即图元 SLAM 的标准惯例（Sparse Point-Plane SLAM；ManhattanSLAM）。blade 系数只作存储/运算格式，不直接赋予概率语义。
- 不确定度传播走**一阶泰勒**穿过代数运算；拟合时由残差 + 灵敏度矩阵给出 $\Sigma$。
- **滤波雅可比约定**：motor-EKF 采用切空间扰动模型——状态扰动 $\delta\xi$（速度二向量坐标），$M \leftarrow \exp(\delta\xi^\wedge)\,M$；观测残差（`dist_*`、关联残差）对 $\delta\xi$ 的雅可比由同一一阶传播给出。拟合灵敏度矩阵与滤波雅可比共用一套扰动机制。
- 贝叶斯后验驻留在稠密域（深度场、类后验）；CGA 图元是其 **MAP 几何 + 局部协方差**。禁止把 blade 系数当作贝叶斯后验参数使用。

### 0.3 数值纪律

- 距离/残差计算一律走 float64 欧氏公式（`cga/algebra.py`，外部包 ~/code/cga，已记录 float32 conformal 内积远原点的灾难性抵消）。
- **残差归一化约定**：`op`/`ip` 关联残差随 blade 权重缩放，凡进入指数/概率表达（亲和度、似然、EKF 残差）前，必须先将 blade 归一化（`normalize()`），使残差具有长度量纲且尺度不变。
- 场景坐标局部归一化（以相机或兴趣点为原点）；长基线跨帧时做原点重定，重定本身是 motor 共轭 $X' = M X \widetilde{M}$。
- CGA 运算只发生在图元层级，不进像素级循环。

### 0.4 文献依据

- Motor-EKF：Bayro-Corrochano & Zhang (2000), "The Motor Extended Kalman Filter", JMIV 13:205–228——时空层运动估计的直接先例。
- CGA 机器人视觉体系：Bayro-Corrochano (2006), JMIV 24:55–81；专著 *Geometric Computing for Perception Action Systems* (Springer, 2001)。
- 关联代数做深度/形状/运动：Bayro-Corrochano & Banarer (2000), ICPR——深集成路线的早期先例。
- 几何约束位姿估计：Rosenhahn 等（Kiel 学派）点-线/点-面约束 + EKF。
- 图元地图 + 高斯不确定度：Sparse Point-Plane SLAM (Hosseinzadeh et al., 2017)；ManhattanSLAM（点/线/面稀疏图 + surfel 稠密残差）。
- 现代对照：Carpenter (2024/25) 在 $G(3,0,1)$（PGA）中做 motor MEKF；Goodarzi & Lee (2016) 矩阵群 SE(3)-EKF。
- CGA 地图构建：DeSouza et al. (IROS 2010)，CGA 线/面检测 + 广义 Hough。

## 1. 知觉组织层（Perceptual Grouping）

**工作空间**：2D 共形子代数 $\{e_1, e_2, e_0, e_\infty\}$（图像平面嵌入），共圆/共线统计是 2D 图像统计（Geisler 共现统计本就是图像域统计）；与 3D 场景图的转换经 $K$ 与深度，见第 3、7 节。
**输入**：$r_{nk}$、$L_e, L_t$、$\theta_n$、$R_n$、邻域共分配相似度。
**输出**：2D CGA 直接形式图元——edgel 点对 $Pp_i$、轮廓线段 $L_j$；T 结集合与遮挡偏序约束；补全弧段可选输出圆 $C_k$（中间量，见下）。

### 数学模型

1. **edgel 提取与提升**：沿 $\theta_n$（法向）对 $L_e$ 非极大抑制 + 亚像素插值，图像点提升为 2D conformal 点 $p_i$（图像平面嵌入 e1-e2 平面，不涉及深度）。**不做反投影**——深度未知时图像点只对应 3D 射线，反投影不是点提升。
2. **亲和度**：共圆性在 CGA 中是原生关联关系。候选共圆 $C_{ij}$ 由**两 edgel 联合确定**：过 $x_i, x_j$ 且分别与两切向相切的圆在几何一致时唯一（单点单切向欠定，不足以确定圆）。亲和度取归一化关联残差的对称形式（圆为对偶形式，判据为 `ip`，残差按 §0.3 归一化）：
$$w_{ij} = \exp\!\Big(-\tfrac{\|x_i - x_j\|^2}{2\sigma_d^2}\Big) \cdot \exp\!\Big(-\kappa \big(|\operatorname{ip}(p_i, \hat{C}_{ij})| + |\operatorname{ip}(p_j, \hat{C}_{ij})|\big)\Big)$$
$\hat{C}_{ij}$ 为归一化后的候选圆。几何不一致（两切向无法共圆）时该项取惩罚常数。良好连续性从角度启发式变为圆关联残差。
3. **轮廓编组**：edgel 图 $G=(V,E)$，轮廓 = 高亲和链；跨缺口补全输出 $p(\text{连续} \mid \text{两端几何})$ 的概率（臆造边缘会制造假深度不连续），不硬连接。链段提升为 `line`（$p_1 \wedge p_2 \wedge e_\infty$）；被高置信补全的弧段可额外输出拟合圆 `circle` 作为编组中间产物。
4. **T 结检测 = 交叉几何代数化 + 中断证据统计化**：线线求交用 `meet`（先 `dual`）给出候选交叉点；但 T 结的核心证据是**竖杠中断**——沿候选被遮线两侧统计 edgel 支撑分布，一侧有支撑一侧无支撑（或被横杠归属区域吸收）者判为 T 结。仅交叉而无中断证据者按 X 交叉处理（不产生偏序）。输出偏序 $A \prec B$ 与边界归属。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 良好连续性 | 格式塔/几何 | 归一化圆关联残差项 |
| 邻近性 | 格式塔 | $w_{ij}$ 的距离项 |
| 闭合性 | 格式塔 | 概率化补全的闭路奖励 |
| 遮挡逻辑（T 结） | 物理 | `meet` 交叉 + 支撑中断统计 → 偏序约束，**极高权重，不被下调** |
| 一般视角 | 几何 | 巧合对齐的解不稳定化处理 |

文献：Geisler et al. (2001) 边缘共现统计；Parent & Zucker (1989)；Ren & Malik (2002) 概率轮廓补全；Dimiccoli & Salembier T 结深度分离。

**实现备注**（`src/grouping.py`，`PerceptualGrouping`）：与设计的三处偏差——① 残差加亚像素定位噪声地板 `res_floor`（像素采样的 edgel 位置有 ±0.15px 量化起伏，相邻对残差被放大、跳点反而更共圆，不加地板会在曲线上产生交错碎链）；② T 结候选除折线求交外增加**链端点延长线**来源（真实 T 的竖杠止于遮挡边、折线本身不相交，直接求交检不出）；③ 支撑判据要求数量与**臂延伸**双达标（防碎链段造成伪 T）。已知限制：L 角点在局部与 T 同构（底边贯穿 + 竖边单侧终止），会被报告为 T 结，需更上层上下文区分；真实管线中竖杠与遮挡边间距超过 `t_radius` 时漏检（端点延长够不到），此时依赖跨缺口补全先行桥接。

## 2. 场景分割层（Scene Segmentation）

**输入**：组织层图元（边界 `line`/归属）、VBGMM 类后验、深度融合层的深度反馈（虚线边，第二轮起）。
**输出**：区域的层级结构与逐像素**软分配** $p(y_n = k)$；区域边界携带 CGA blade 引用。

### 数学模型

1. **层级分割**：有向边界强度 → 分水岭 → 超度量等高线图（UCM），边界归属决定分水岭方向（gPb-owt-ucm 范式）。
2. **区域标注的层级贝叶斯网络**（替代 MRF/CRF，全架构统一为有向图）：

   联合分布分解为三层生成过程：
   $$p(R, S, Y \mid I, L, D) = p(R \mid I, D) \cdot p(S \mid R, L) \cdot \prod_n p(y_n \mid S_{\operatorname{parent}(n)}, I_n)$$

   - **区域层 $R$**：UCM 等高线层级作为离散假设空间，先验 $p(R \mid I, D)$ 由 VBGMM 类后验 $I$ 与深度不连续反馈 $D$ 共同调制——$D$ 提升边界处的高层级概率。
   - **子区域层 $S$**：给定 $R$ 与组织层轮廓图元 $L$，$p(S \mid R, L)$ 以 $L$ 为硬约束做确定性分割（轮廓线强制切开区域），无轮廓处按距离场软过渡。轮廓图元携带 CGA blade 引用，分割结果的区域边界继承同一条 blade 句柄。
   - **像素层 $Y$**：$p(y_n \mid S, I_n)$ 为多项分布，子区域 $S$ 给出类别先验（区域内近似 i.i.d.），像素级 VBGMM 后验 $I_n$ 调制具体取值。VBGMM 平均场后验系统性偏尖，需温度缩放后注入。

   **平滑性来源**：不再由像素-像素成对势（Potts）显式编码，而是下沉为"同一子区域内标签共享先验"的层级约束——像素间的平滑性由共同父节点 $S$ 隐式生成。跨子区域独立，自然满足边界处不连续。

   **推断**：R 层遍历（或带先验采样）→ S 层图割/洪水填充（确定性）→ Y 层各子区域并行 MAP。复杂度从全局 MRF 迭代降为线性于像素数。
3. **软分配保留**：输出逐类后验而非硬标签；区域（而非像素）是后续平面提升的拟合单元。
4. **与融合层的迭代协议**：首轮为纯视觉前馈（无深度反馈）；融合层产出后，深度反馈自第二轮起注入。实现形态（2026-08-10 核实）：闭环逐帧注入上轮场景渲染的 prior_map（即"第二轮"语义），不在帧内跑显式定点循环——协议上限 2 轮以"每帧一轮反馈"落地；未收敛差异按"分歧保留"处理（区域边界同时保留视觉版与深度修正版，交由融合层裁决）。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 紧凑性与平滑性 | 几何 | 子区域内部高斯先验（层级 BN 隐式编码）|
| 邻近性 | 格式塔 | 区域层先验 $p(R \mid I)$ 的距离调制 |

## 3. 单目深度线索（Monocular Cues）

**输入**：组织层（遮挡、2D CGA 边界图元）、分割层（语义、区域）、特征层谱统计。
**输出**：逐线索的深度分布（度量线索）或偏序约束（序数线索），始终可用。

### 数学模型（逐线索通道）

1. **遮挡**：T 结偏序 $A \prec B$——严格序数约束，任何距离成立；融合中作为（近）硬约束。
2. **纹理梯度**（Gibson，**实验性通道，初始权重为零**）：纹理尺度随距离单调收缩，$\nabla d \propto -\nabla \hat{s}$。注意 `bump`/`centroid` 只是 4–8 个 log 间隔离散尺度上的统计，对连续透视漂移率的估计精度未经合成数据标定前不得启用。
3. **线性透视**：在**图像空间**（2D CGA）对图像线段 `line` 求交（`meet`）得灭点图像坐标；对应 3D 方向经 $K^{-1}$ 反投影射线恢复（灭点方向不依赖深度，这是唯一不需要深度即可完成的 2D→3D 转换）。三正交方向灭点给出曼哈顿框架初值（与重建层共享）。
4. **大气透视**：$C(d) = C_0 e^{-\beta d}$，由 `log_mag`/`spread` 读出；仅户外远距有效。
5. **明暗成形**：$I = \rho \max(0, \mathbf{n} \cdot \mathbf{l})$，光源上方 + 单一光源 + 反照率恒常三先验下求解（光源方向本身见缺口 C7）。
6. **视平线高度**：地平面物体底边纵坐标 → 距离。
7. **熟悉大小**：类别 $c$ + 像素张角 $\omega$ → $d \approx h_c / \omega$，低频通道。

### 注入的先验

| 先验 | 类别 | 通道 |
|---|---|---|
| 遮挡逻辑 | 物理 | T 结偏序 |
| 大气透视、视平线 | 物理 | 通道 4、6 |
| 光源上方、单一光源、反照率恒常 | 光学 | 通道 5 |
| 线性透视、一般视角 | 几何 | 通道 3（图像 `meet` + $K^{-1}$） |
| 熟悉大小 | 语义 | 通道 7 |

文献：Knill & Richards (1996) 贝叶斯线索整合；Gibson (1950) 纹理梯度。

## 4. 双眼视差估计（Stereo Disparity）

**输入**：双视点图像对、组织层的边界与朝向。
**输出**：稠密视差图 $d_n$ 及置信度。

### 数学模型

**空间自回归贝叶斯网络**（替代 MRF 能量最小化，全架构统一为有向图）：

$$p(d \mid I_L, I_R, L_e, \theta) = \prod_n p(d_n \mid d_{\mathcal{N}^<(n)}, I_n, L_e, \theta_n)$$

其中 $\mathcal{N}^<(n)$ 为光栅扫描序中先于像素 $n$ 的邻居（左、上、左上）。

- **条件概率** $p(d_n \mid \cdot) = \operatorname{Cat}(\boldsymbol{\pi}_n)$：轻量 CNN $f_\theta$ 输出类别概率 $\boldsymbol{\pi}_n$，输入包括左右图像特征 $I_n, I'_n$、已推断邻居视差 $d_{\mathcal{N}^<(n)}$、边缘图 $L_e$ 与法向 $\theta_n$。
- **平滑先验编码在网络中**：$f_\theta$ 学习到——$L_e$ 低（非边缘）时 $d_n$ 倾向接近邻居；$L_e$ 高且 $\theta_n$ 指向该边时允许跳变。边缘切向/法向的各向异性平滑由 $L_e$ 与 $\theta_n$ 联合门控，不再显式写成成对势。
- **数据项**：左右特征匹配代价嵌入 CNN 输入，增益控制保障曝光差稳健性。
- **唯一性约束**：左右匹配一一对应，遮挡区显式标记。
- **双向扫描修正**：单遍光栅序引入人为不对称，执行左上→右下与右下→左上两趟，取对数概率和最大者。复杂度仍为线性。
- （可选）线特征匹配：组织层输出的 `line` 作为匹配基元，线-线对应进入后续 motor 估计（见第 6 节）。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 表面平滑 | 几何 | CNN $f_\theta$ 的非边缘区一致偏好 |
| 物体边界 ↔ 深度不连续 | 几何/物理 | $L_e$ 与 $\theta_n$ 联合门控跳变 |
| 唯一性 | 几何 | 匹配约束 |

文献：Hirschmüller (2008) SGM；PL-SLAM（线图元双目先例）；Frey (1998) 图像建模中的置信网络（自回归 BN 图像分割先例）。MRF 能量框架（Kolmogorov & Zabih 2004）仅作历史对照，本架构以自回归 BN 替代。

## 5. 深度融合层（Depth Fusion）—— 分层 2.5D 草图的图元化，**BN 推断**

> 概率图类型：**贝叶斯网络**——多父节点（单目线索、双目视差、运动预测、重建反馈）的条件概率聚合，即贝叶斯乘积法则。

**输入**：单目各线索、双目视差（带置信度）、分割层软分配（迭代协议见第 2 节）、时空层运动视差预测（虚线边，共享渲染功能）、重建层预测编码（虚线边）。
**输出**：分层 2.5D 草图——每层的几何载体是 **CGA 图元（plane/sphere blade）+ 最小参数协方差**，逐像素逐层软分配权重作为伴随场保留。

### 数学模型

1. **贝叶斯线索整合**（稠密域不变）：
$$p(d \mid c_1, \dots, c_M) \propto p(d) \prod_{i=1}^{M} p(c_i \mid d)^{w_i}$$
$w_i$ 逆方差加权；遮挡偏序作为约束集，不参与加权表决。
2. **区域提升（本层的 CGA 转换点）**：以分割层区域为拟合单元，把稠密深度后验提升为图元——平面 $(\mathbf{n}, d)$ 或球 $(\mathbf{c}, \rho)$ 的加权最小二乘拟合，权重 = 深度后验精度 × 区域软分配；输出图元参数 + 灵敏度矩阵一阶传播的协方差 $\Sigma$。注意软分配与一元势同源（VBGMM 平均场后验偏尖），权重校准沿用第 2 节的温度缩放。分段平滑深度先验 $p(d)$ 在图元化后**从正则项升格为表示本身**（平面层天然分段平滑）。
3. **分层表示**：每像素维护多层软分配；底层（base）优先图元化，反光/透明层按需分裂（触发判据见缺口 C6），未图元化的残差保留稠密场。
4. **曼哈顿耦合**：图元法向直方图聚类；三正交聚类显著时对平面组施加 $\operatorname{ip}(\mathbf{n}_i, \mathbf{n}_j) = 0$ 约束（法向点积为零），以约束最小二乘重投影精化平面组（与重建层共享的约束机制）。
5. **深度反馈 → 分割层**（虚线边）：图元不连续修正区域边界，按第 2 节迭代协议执行。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 分段平滑/紧凑 | 几何 | 图元化表示本身 |
| 分层与软分配 | 分层 | 多层结构 |
| 遮挡序数 | 物理 | 约束集（高权重） |
| 平直与正交 | 几何 | 曼哈顿法向约束 $\operatorname{ip}(\mathbf{n}_i, \mathbf{n}_j)=0$ |

文献：Knill & Richards (1996)；Sparse Point-Plane SLAM（图元 + 协方差惯例）。

## 6. 时空累积层（Temporal Fusion）—— motor 流形上的状态估计，**动态 BN**

> 概率图类型：**动态贝叶斯网络（Dynamic Bayesian Network）**——时序 DAG $x_{t-1} \to x_t \to z_t$，状态转移 + 观测更新。Motor-EKF 为其在连续状态、切空间线性近似下的具体实现。

**输入**：融合层逐帧 2.5D 草图（图元 + 伴随场）、帧间图元对应。
**输出**：时域累积的图元场景与运动模型；向融合层输出运动视差预测（虚线边，调用共享渲染功能）。

### 数学模型

1. **运动状态 = motor**。相机自运动与物体运动一律以 motor $M$（偶次 versor）表示；图元跨帧变换 $X_t = M X_{t-1} \widetilde{M}$。
2. **motor 流形上的 EKF**（Motor-EKF，Bayro-Corrochano & Zhang 2000）：状态向量取切空间坐标——$\operatorname{log}(M)$ 得速度二向量（twist），预测-更新在切空间线性进行，`exp_bivector` 映回；扰动模型与观测雅可比按 §0.2 约定。转移模型编码运动先验：速度一致性、加速度限制、低速平滑。观测模型用统一对应类型：点-点（`dist_point_point`）、点-面（`dist_point_plane`）、线-线（归一化关联残差）混合进入同一 versor 优化。
3. **运动补偿的 warm**：VBGMM 的 `warm` **必须先补偿再复用**——按 motor 预测 $M_{t|t-1}$ 把上帧特征/责任场扭曲到当前帧视角，再作为初始化；小运动（扭曲量 < 特征核波长）时可退化为原样复用。否则 warm 在大运动下把错位的后验当作先验，反而有害。
4. **最小刚性**：多解时选刚体运动解释——即优先用单一 motor 解释全部对应（Ullman SfM 的 versor 形式）。动态场景的检测/剔除见缺口 C4。
5. **不变性假设**：跨帧特征可比性（增益控制保障）是对应建立的前提。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 运动连续性、低速平滑 | 运动 | 切空间转移模型 |
| 时间一致性 | 时间 | 自环虚线边；运动补偿 warm |
| 不变性假设 | 时间 | 观测模型 |
| 最小刚性 | 几何/运动 | 单 motor 解释偏好 |

文献：Bayro-Corrochano & Zhang (2000) Motor-EKF；Weiss et al. (2002) 低速先验；Sato (2001) online VB；Ullman (1979) SfM。

## 7. 三维重建层（3D Reconstruction）—— CGA 图元场景图，**BN 递推更新**

> 概率图类型：**贝叶斯网络递推**——图元累积 = 信息滤波（协方差加权后验更新），预测编码 = 观测似然驱动的新一轮 BN 推断。静态 BN 结构随图元节点增减动态扩展。

**输入**：时空累积的图元流（带协方差）与运动轨迹（motor 序列）。
**输出**：**CGA 图元场景图** + 稠密残差场（混合表示）；向特征/分割/融合层输出预测编码（虚线边，共享渲染功能）。

### 数学模型

1. **场景图结构**：节点 = CGA 图元（plane/sphere/circle/line blade + 最小参数协方差 $\Sigma$）；边 = 关联关系（`meet` 求交、`op`/`ip` 关联判据）——相交、平行、正交、相切、共面。运动节点 = motor（相机轨迹与刚体运动）。
2. **图元累积**：同名图元的跨帧融合 = 最小参数空间的信息滤波（协方差加权平均），等效 TSDF 加权融合的图元版；曼哈顿组施加正交约束联合精化。
3. **对称补全**：检测到的对称面 → 反射 versor 共轭 $X' = R X \widetilde{R}$ 补全不可见半侧（反射是 grade-1 versor，与 motor 同一代数）。
4. **混合表示与仲裁规则**：未被图元解释的几何保留为深度/surfel 场（ManhattanSLAM 式混合）。图元与残差场冲突时按证据仲裁：图元拟合残差持续超过其 $\Sigma$ 包络（如 $>3\sigma$ 若干帧）→ 图元失效退场，区域交还残差场；残差场区域出现高置信平面证据 → 触发新图元提升，成功后残差场相应收缩。禁止图元与残差长期矛盾共存。
5. **预测编码闭环**：从新视点渲染 = 射线（`line`）与场景图 `meet`，残差用 `dist_*`（float64）计算，驱动三条反馈边——特征层（残差突出新信息）、分割层（修正区域）、融合层（修正深度/图元）。

### 注入的先验

| 先验 | 类别 | 位置 |
|---|---|---|
| 平直与正交（曼哈顿世界） | 几何 | 法向约束 $\operatorname{ip}(\mathbf{n}_i,\mathbf{n}_j)=0$ |
| 对称性 | 几何 | 反射 versor 补全 |
| 凸形状偏好 | 几何 | 模糊形状解释 |
| 紧凑性 | 几何 | 图元信息滤波融合 |
| 物体边界 ↔ 强梯度 | 几何 | 图元-边界一致性 |

文献：ManhattanSLAM（混合表示先例）；DeSouza et al. (2010) CGA 地图；Bayro-Corrochano & Banarer (2000) 关联代数。

## 8. 已知缺口与生物启发方案

以下缺口按"人类视觉系统如何解决同一问题"的思路给出方案。每条含：生物先例 → 管线设计 → 落点与阶段。生物先例均有实验文献支撑，但**方案本身是外推，需合成数据验证后方可采信**。

### C1. 标定 → 慢速在线标定环

- **生物先例**：眼睛不存内参表。光学端由 emmetropization（视网膜模糊反馈调节眼轴生长）自我标定；神经映射靠感觉-运动闭环终身重标定（棱镜适应；Held & Hein 主动运动实验）；坐标变换用传出副本（efference copy）与增益场在线完成，而非反解常量矩阵。
- **设计**：$K$ 作为**慢变状态**挂入时空累积层，与 motor-EKF 同构但时间常数大几个数量级（秒至分钟级）。驱动信号取自预测编码残差的**系统性模式**：直线投影的弯曲残差（畸变）、曼哈顿正交约束残差（焦距误差会扭曲正交性）、运动视差预测与实测的长期不一致（efference copy 类比的失效）。离线棋盘格标定仍是首选初值，在线环只负责漂移修正，增益取小（学习率 ≪ 帧率）。
- **落点**：时空层新增慢通道；阻塞关系不变——第三步（融合图元化）实现前，$K$ 至少要有离线初值。

### C2. 冷启动 → 序数优先、度量后至

- **生物先例**：发育顺序——婴儿先获得运动/遮挡等序数-拓扑结构（物体永久性、遮挡关系在约 4 月龄即出现），度量尺寸与距离判断远晚于此；关键期研究（Hubel & Wiesel）表明低级通路先于高级通路定型。
- **设计**：冷启动协议分两期。**序数期**（前 N 帧）：只运行特征层 + 组织层 + 遮挡偏序，产出 2D 编组图与拓扑场景图（节点 = 轮廓/区域，边 = 遮挡/邻接），不做任何度量图元拟合；motor 从两视图约束（纯旋转假设检验 → 退化则本质矩阵类约束）初始化。**度量期**：首个尺度锚出现（见 C3）后，深度通路开放，序数期积累的偏序作为约束直接进入融合层。

  **实测域界 (2026-08-10, iBims/NYU 评估)**：序数期依赖纹理驱动前端 (边缘/T 结/区域), 而该前端在室内实数据上不可靠 —— 单目纹理线索 Spearman≈0、遮挡序数约束端到端序正确率 ≈0.42 (≈随机, E4-E7 判别排除定向噪声/区域 confound, 剩余在结点级 through/stub 分类与假 T 几何歧义)、边界供给不足 (工作 τ 遮挡界 recall 10-32%)。**域界声明**: 单图序数/遮挡机制的有效域是自然纹理场景 (合成/自然图自检通过); 室内场景序数期无法自举, 度量深度由运动视差通道承担 (双通道设计意图)。**风险封堵**: 闭环注入融合的序数约束经自身深度估计验证 (分歧丢弃, realtime.py `_loop_hook` 验证门) —— 未验证硬约束会主动扭曲深度。
- **落点**：第 1、7 层增加"序数模式"输出规格；第三步落地按此协议实现。

### C3. 尺度锚定 → 身体尺度（embodiment）的优先级链

- **生物先例**：人类的绝对尺度几乎全部来自**身体**：视平线=眼高（`prior.md` 物理先验）、臂展（可达性）、步幅（行走校准运动视差）；非身体的只剩熟悉大小。没有一条来自纯视觉。
- **设计**：尺度锚**优先级链**：双目基线（硬件常量）＞ 外部运动幅值（IMU/轮速计）＞ 安装高度（视平线通道）＞ 熟悉大小（语义，最不可靠，仅作一致性校验）。约定：首个高优先级锚出现前，所有深度与图元保持**相对量纲**，协方差 $\Sigma$ 带"尺度未定"标记；锚出现后一次性重定标（图元参数线性缩放的协方差传播）。
- **落点**：第 5 层（融合）输出规格增加量纲标记；纯单目无 IMU 配置下接受相对尺度运行。

### C4. 动态场景 → flow parsing + 共同命运

- **生物先例**：flow parsing（Rushton & Warren 2005, *Current Biology*）：大脑从视网膜运动场中**减去**自我运动成分，残差即物体运动；Warren & Rushton (2009) 证明单目深度线索足以支撑该机制，无需立体视差。格式塔"共同命运"负责把残差聚成整体。
- **设计**：motor-EKF 的观测残差场（逐像素/逐图元）即 flow parsing 的计算形式——**残差即运动分割图**。持续高残差区域按共同命运聚类 → 动态物体假设 → 切出独立 motor 估计（多 motor 竞争：静态场景一个 motor，动态物体各一个）；动态区域从静态融合/累积中屏蔽，但保留其 2.5D 表示。
- **落点**：第 6 层（时空）为主，第 5 层加动态屏蔽位。该方案同时是 §6.3 运动补偿 warm 的外点处理。

### C5. 全局一致性 → 认知地图的双重表征

- **生物先例**：Tolman (1948) 认知地图；O'Keefe & Nadel (1978) 海马体即认知地图；位置细胞/网格细胞体系 = 路径积分（自运动信号，会漂移）+ 地标锚定（网格相位相对地标重锚）。地图组织为**局部图（local chart）+ 图结构**（chart 内局部度量，chart 间邻接）。
- **设计**：双重表征。**自我中心局部图**：当前 2.5D 草图 + 图元场景（即现有第 7 层，不变）。**非自我中心地图图**：节点 = 场景锚点（位置识别指纹：全局谱统计 + 图元配置签名），边 = motor 相对位姿。路径积分由 motor-EKF 承担（会漂移）；锚点再识别触发**回环校正**——motor 位姿图优化，随后局部图重锚定。频率：锚点检测中频（秒级），图优化低频（事件触发）。
- **落点**：第 7 层新增地图图组件；位置识别复用特征层谱统计，不新增特征通路。

### C6. 分层触发 → 三条可计算判据

- **生物先例**：`prior.md` 已列——X 结的 Metelli 混合定律、聚焦/模糊差、（补充）透明运动分层（两层各自运动一致时大脑立即分层）。
- **设计**：分裂判据三条，满足其一即生成层假设：**(a) X 结光度检验**：交叉点亮度是否落在两层亮度的凸组合内（Metelli 约束，逐 X 结可算）；**(b) 频率差检验**：X 结两侧区域的 `spread`/`residual` 差异超阈（模糊层 vs 清晰层）；**(c) 运动分层检验**：flow parsing 残差显示同一区域存在两个各自一致的运动场。层假设生成后，软分配允许"双父"（像素同时属于 base 与透明层）；判据持续不成立则层合并退场。
- **落点**：第 1 层（X 结检测随 T 结同路产出）+ 第 5 层（分裂/合并规则）。

### C7. 光源估计 → 可适应的默认先验

- **生物先例**：Adams, Graf & Ernst (2004, *Nature Neuroscience*)：光源上方先验**可被经验修改**——它是默认值而非常量，适配由长期统计驱动。
- **设计**：光源方向建模为慢变状态（与 C1 标定环共用慢通道基础设施）。初值 = 光源上方；适配信号 = 阴影边界统计（方向一致的弱亮度阶跃，`phase_coh` 高而 `log_mag` 低的定向边缘）与 SfS 残差的长期模式。适配速率取小，置信度门控——证据不足时保持默认，防止短期异常场景带偏。
- **落点**：第 3 层（SfS 通道）+ 慢通道。

### C8. 调度 → 扫视式主动视觉的三档节奏

- **生物先例**：主动视觉——周边视觉低精度高覆盖（常驻），中央凹高精度窄视野（扫视调度，3–4 Hz），显著性/意外事件捕获扫视（事件驱动）。计算资源按时序分配，而非均匀铺开。
- **设计**：三档节奏。**快通路（每帧，类比周边视觉）**：特征提取 + warm VB + `infer()`，毫秒级、全图、允许低精度。**慢通路（周期 + 事件触发，类比扫视）**：组织/分割/融合全量、全局优化——周期基线（如 1–2 Hz）+ **surprise 中断**（预测编码残差超阈立即调度）。帧预算按"快通路常驻 ≤ 30% 算力，慢通路抢占式"分配。
- **落点**：管线级调度器（新组件，横切各层）；surprise 信号取自第 7 层渲染残差。

### C9. 评测协议 → 错觉回归测试 + 标准基准

- **生物先例**：心理物理方法论——错觉是先验存在的直接证据；若系统的先验实现正确，它应当在经典错觉上**犯和人一样的错**。
- **设计**：双层评测。**先验回归测试**（错觉测试集）：空心面具（应判凸）、Adelson 棋盘阴影（应误判亮度）、旋转 180° 凹凸反转（光源先验）、T 结合成图（偏序正确率）——先验模块改动后跑此集，防先验退化。**工程基准**：BSDS500（对 Pb/gPb，软边界图 F-measure）、sklearn `BayesianGaussianMixture` 对拍（ELBO 与 K_eff 一致性）、Kovesi phase congruency 边缘图对照、Middlebury stereo / TUM RGB-D（深度与轨迹精度）。
- **落点**：新组件 `tests/`，与管线并行开发；错觉测试集先行（无需外部数据）。

## 深集成带来的横切变化（相对非 CGA 架构）

1. **几何先验获得统一代数语言**：良好连续性（归一化圆关联残差）、曼哈顿（法向正交 `ip=0`）、遮挡（`meet` 交叉 + 中断统计）、对称（反射 versor）、刚性运动（motor）——原本散落在各层的启发式统一为 blade 关联/versor 运算。
2. **新增架构构件**：不确定度接口（最小参数 + 协方差，一阶传播 + 切空间扰动雅可比）、稠密/稀疏边界（提升点 ×2、渲染为共享功能 ×2 处调用）、残差归一化约定、2D/3D 两个 CGA 空间的映射规则——这是方案 B 比方案 A（CGA 仅作出口适配）多出的主要设计工作。
3. **分阶段落地**：
   - 第一步：重建层 CGA 出口（平面拟合 + motor 轨迹），上游零改动，外部包 `cga`（~/code/cga）现有功能已够；
   - 第二步：时空层迁移 motor 流形滤波（含运动补偿 warm），组织层 edgel 输出 blade 并实验共圆亲和度；
   - 第三步：融合层区域提升 + 曼哈顿耦合，预测编码走 `meet` 渲染——深集成完成态。第三步按 C2 冷启动协议实现，且之前须取得离线 $K$ 初值（C1）；C4–C9 的方案实现可与第三步并行（见第 8 节状态表）。

与 `prior.md` 六类先验的对应：光学 → 特征层（已述）与单目线索层；几何 → 组织/分割/双目/融合/重建各层（深集成后大部分几何先验以 CGA 约束形式表达）；物理 → 组织层（遮挡）与单目线索层；运动与时间 → 时空累积层（motor 流形）；语义 → 分割层入口与单目线索层（低频通道）；分层 → 分割层与融合层的软分配结构。

## 附录 A：模块间数据格式总表

模块间只存在三类载体：**稠密场**（(H,W) 或 (N,·) 逐像素数组，float32）、**图元**（CGA blade + 最小参数 + 协方差 Σ，残差计算 float64）、**约束**（偏序/对应/标记，非数值场）。像素域与图元域之间只允许经 §0.1 的两个提升点与渲染功能转换。

### A.3 格式纪律（跨层通用）

- 稠密场一律 float32；进入 CGA 残差/`dist_*` 计算一律 float64（§0.3）。
- 图元跨层传递 = blade（存储/运算格式）+ 最小参数化 + Σ（概率语义只在最小参数上，§0.2）；blade 进概率表达前必须 `normalize()`。
- 2D 量（组织层）与 3D 量（融合层以下）是两个空间的对象，唯一无深度转换是灭点方向（$K^{-1}$ 反投影射线，§3 通道 3）；其余 2D→3D 必须经深度。
- 尺度未定期间（C3），深度与图元参数带"尺度未定"标记，锚定后一次性线性重定标（Σ 同步传播）。
