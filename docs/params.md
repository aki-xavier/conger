# 参数清单与自适应探索

盘点 `src/` 全部人工设定参数，逐项评估自适应可行性。`docs/flow.md` 中尚未实现的设计期参数单列一节。

## 自适应的统一框架

评估每个参数时适用三条原则：

1. **经验贝叶斯（证据最大化）**：与项目的贝叶斯哲学一致——超参数的正当自适应形式是在 ELBO（或其代理目标）上做类型-II 最大似然，而不是另起启发式。VBGMM 自带 ELBO，这是现成裁判。
2. **时间尺度分离**：推断快、适配慢（与 `flow.md` C1/C7 的慢通道同一原则）。每个自适应参数都是一个新的反馈环，环增益必须小、周期必须长，否则跨帧振荡。凡自适应项必须带滞回或速率限制。
3. **不变性约束**：跨帧聚类一致性（`prior.md` 不变性假设）要求**滤波器组结构冻结**——凡改变特征定义本身的参数（带宽、核形、方向数）不得在线自适应，只能在离线标定时选择，改动触发相干底线重标定。

## A. 已实现自适应（现状盘点）

| 参数 | 位置 | 自适应机制 |
|---|---|---|
| 噪声能量 floor | `riesz.py` 增益控制① | 最细尺度 `b0` 的 MAD 估计 σ̂ → Parseval 推导逐尺度噪声能量，逐帧在线 |
| 相干特征底线 | `riesz.py` `_coherence_floor` | 合成白噪声标定滤波器组属性，按 (形状, 尺度数, 带宽, lam_min) 缓存 |
| `log_mag` 局部归一 | `riesz.py` 增益控制③ | Retinex 式减邻域均值，逐像素在线 |
| `scale_size` | `riesz.py:72` | 由图像尺寸自动推导 `max(4, log2(lam_max/lam_min)+1)` |
| `pad` | `riesz.py:88` | 自适应 `= lam_max`（`adaptive_pad=True`） |
| 有效分量数 K_eff | `vbgmm.py` | ARD：`alpha0` 稀疏先验剪枝，数据决定 |

## B. 推荐自适应（有明确估计量，风险低）

| 参数 | 位置 / 现值 | 自适应方案 | 依据与风险 |
|---|---|---|---|
| `subsample` | `vbgmm.py:118`，0/8192 | **按帧预算自适应**：subsample = f(N, 快通路预算)，由调度器（flow.md C8）下发 | 充分统计量对子采样稳健（代码注释已证），纯调度参数，无模型语义。风险：无 |
| S_k 正则 `1e-3` | `vbgmm.py:205` | ~~Ledoit-Wolf 收缩~~ → **已改为逐分量特征值地板**（实测 LW 不可行，见 §H） | LW 是成熟的解析估计量；与现有"饱和特征防 W 爆炸"目的一致且更紧。风险：低，需对拍 ELBO 验证 |
| 类证据阈值 | `vbgmm.py:314-321`（resid<1.0、spread>1.0、phase_coh>0.4 等 7 个） | **锚点相对化**：阈值不再用绝对常数，改为标定锚点间的相对位置（phase_coh 锚点已知：平坦≈0.17/纹理≈0.34/边缘≈0.55，且噪声底线已自适应）；每图用分位数/Otsu 校验锚点漂移 | 现值是合成真值上调出的，自然图上分布漂移是最脆弱的一环。风险：中——阈值自适应影响证据定义本身，需保留合成回归测试 |
| `_box_mean` 窗 k=15 | `riesz.py:283` | **尺度绑定**：k 取 λ_max 的小数倍（奇数），随图像尺寸自适应 | Retinex 窗应与"局部"的物理尺度挂钩而非固定像素数。风险：低 |
| `hops` / `dir_smooth` | `edgemap.py:187-188`，(1,2,4,8) / 6 | **尺度绑定**：桥接半径与方向内绘轮数绑定到核波长（如 λ_min 的倍数），随滤波器组配置推导 | 两者语义就是"可桥接缺口半径（px）"（注释原文），像素值应随分辨率/核尺度缩放。风险：低 |

## E. 测试专用参数（不在自适应范围）

`utils.py` 全部合成信号参数（`size`、`wavelength`、`boundary`、灰度值等）是**真值生成器**的输入——它们定义测试而非定义系统，必须保持手动且固定，否则回归测试失去意义。`cga/` 的构造器默认值（如 `rotation_angle=0.0`）是 API 便利默认，非调优参数。

## G. 实施优先级

1. **零风险先行**：`subsample` 预算化、传播早停（ε 定点检测）、`_box_mean`/hops/dir_smooth 尺度绑定——纯调度与尺度推导，不动模型语义。
2. **对拍验证后上线**：S_k 正则自适应化（落地为特征值地板，LW 路线实测弃用，见 §H）、类证据阈值锚点化（需先建合成回归测试，flow.md C9）。
3. **冷启动限定**：alpha0 经验贝叶斯网格——只在冷启动、只在网格上、选定即冻结。
4. **不做**：滤波器组结构参数在线自适应、慢通道学习率自适应。

每项自适应上线前必须过 `flow.md` C9 的评测协议（错觉回归测试 + 合成真值），并满足原则 2（滞回/限速）。

### Ledoit-Wolf 弃用记录（原 B 组推荐方案的实测结论）

1. **无封顶 LW 打破 ELBO 单调性**：收缩使 M 步偏离精确最大化器过远，合成测试最大回退 556（基线 175）、100 轮不收敛、暖启动丢弱边缘（weak@72: 0.47 → 0.06）。封顶 λ≤0.1 可修复此项（回退 379，弱边缘恢复 0.50）。
2. **封顶 LW 仍产生 NaN**：S_k = m2 − x̄x̄ᵀ 的相消在 float32 下产生 O(1e-4) 负特征值；大分量（N_k ≈ 1.2e4）在 Frobenius 意义下"良态"，LW 估计 λ≈0，负方向无修正 → N_k·λ < −1 → W⁻¹ 不定 → inv 出不定 W → maha 为负 → 整行 log_rho −inf → 责任全 NaN（nat10 第 32 轮爆发，表现为 K_eff=0）。
3. **结论**：危险来自单方向的负/零特征值而非整体收缩强度，特征值地板是外科手术式修正——逐分量 `eigh`（7×7，CPU stream，成本可忽略）钳底 1e-3·μ，同时覆盖"饱和/量化特征近零方差防爆"（原 1e-3 正则的职能）与"负特征值兜底"两个目标，且 M 步仍贴近精确最大化器。

### 对拍结果（HEAD 基线 → 本版）

- 合成探针：weak edge 0.48→0.47、strong edge 0.97→0.92、gap 桥接 0.30→0.30、blob 抑制 0.01→0.02、平坦区 0.00→0.00、脊线宽 2px @127 不变。
- 自然图 K_eff（12/nat10/nat1015/nat1016/nat1018/nat1035）：31/29/28/26/28/27 → 29/30/24/25/26/24，同量级，无 NaN。
- 暖启动 frame2：weak@72 0.47→0.44、strong@136 0.91→0.87，跟踪能力保持。
- ELBO 非单调性是两版共有现象（基线最大回退 175，本版 559；任何正则化都使 M 步偏离精确最大化器），功能指标不受影响；收敛判定本就把下降视为"不收敛继续迭代"而非错误退出。
- 12.png 的 ELBO 起止值两版不可直接比较：retinex 窗尺度绑定后该图 k 从 15 变为 ~57，log_mag 特征本身已变。
- α0 网格验证：合成数据上选中 1e-2，与单跑各候选的 ELBO 最优一致，后验/责任/elbo 状态恢复正确。
